# Social post production skill

1. Read `brand/voice-and-tone.md`, `playbooks/social-publishing.md`, `policy/claims-and-consent.md` and approved campaign concept/copy.
2. Confirm intended audience and single CTA; check current app behavior and link destination.
3. Create LinkedIn and Instagram variants only when channel fit is justified. Include alt text, image/video specifications and UTMs.
4. Social Manager may create publishing packages and moderation notes; Copywriter owns the wording, Graphic Designer owns the static output.
5. Hand actual final graphics/footage to Brand Lead. A textual design prompt is **not a rendered design**.
6. Mark status as draft until human-approved and actually posted by an authorized service. Never fabricate URLs, account access, community replies or engagement.
