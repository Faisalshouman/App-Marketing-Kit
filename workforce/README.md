# Employee definitions

The 13 `roles/*.md` files are the *only canonical operational job descriptions*. `roles/manifest.json` stores names and short descriptions required to generate native Codex and Claude agent adapters. Generate the adapters with `npm run sync:agents`.

Role owners should work on small campaign-scoped deliverables, not perform invisible all-company tasks. The primary session owns shared workboard mutations; never let parallel subagents concurrently edit `data/work-items`.

Use the [role-to-skill map](skill-map.md) to choose installed skills for each role's deliverables.

The [creator-clipping playbook](../playbooks/creator-clipping.md) covers independent gaming clips and podcast excerpts. The human selects and captures the source, Video Production owns the creative edit, and the Media Pipeline Engineer owns reusable media tooling and its technical checks.
