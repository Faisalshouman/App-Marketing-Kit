# Brand review skill

1. Read `brand/brand-guidelines.md`, `brand/brand-system.json`, `brand/asset-manifest.json`, `policy/claims-and-consent.md`, `playbooks/brand-audit.md`.
2. Inspect **actual rendered** asset and source, not only prose. If not rendered, classify review as PRELIMINARY and block final approval.
3. Check that the official logo is genuine, colors are approved and current deployment was verified where relevant; don't invent an SVG.
4. Check actual legibility, contrast, platform-safe cropping, subtitle readability, video source/rights, truthful app states and relevant CTA.
5. Write `templates/brand-review.md` format with severity, evidence and next owner, including errors requiring creative revision.
6. Do not call `work:approve`: this review is not founder publication authorization.
