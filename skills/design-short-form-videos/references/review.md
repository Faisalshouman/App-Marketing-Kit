# Review

Start with the most consequential defect in the requested deliverable. Give the exact beat, the observed problem, and the smallest useful edit.

| Check | Evidence to inspect |
| --- | --- |
| First frame and first beat | Start at frame zero, including once with the sound off. Confirm the subject is legible and the first cue directs attention to something visible. |
| Payoff and claims | Trace the opening promise to a completed answer. Check source timestamps, screen labels, speaker intent, and qualifications. Confirm the most important claim matches the evidence. |
| Caption and framing | Play at phone size. Check timing, key-shot visibility, text wrapping, caption contrast and interface clearance for the intended placement. |
| Replay join | Preview two copies back-to-back with and without sound. Check the last and first frames, caption pop, duplicated frames, audio reset, and whether the first play makes sense by itself. |
| Export | When a rendered file exists, check dimensions, duration, audio, playback, and a few key frames using available local tools. Distinguish a storyboard review from rendered playback verification. |

For an optical puzzle, hand the clip to first-time viewers and ask what they saw before and after the reveal. For a spoken clip, ask what claim the speaker made. Use the replies to find confusion, then inspect the edit at that point.

Test one edit variable at a time. Compare opening variants against an otherwise matched cut. Compare loop variants using the same opening and payoff. For a private preview, avoid showing the same puzzle twice to the same person when evaluating first impressions. For published comparisons, use the existing analytics workflow if available and keep differences in topic, timing, or distribution visible. YouTube public Shorts views include starts and replays, while engaged views exclude loops. Read early choice, viewing duration, and shares together. A replay spike can reflect interest or confusion.
