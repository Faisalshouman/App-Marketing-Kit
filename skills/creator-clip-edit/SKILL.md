# Creator clip edit

Use this skill as Video Producer. Start with `playbooks/creator-clipping.md` and the assigned clip brief.

1. Check that the source is human-selected and supplied, the rights reference covers the intended edit and channel, and embedded third-party material has a clearance decision. Route gaps to Partnerships and the founder.
2. Review the full supplied moment for context. Choose in/out points, hook placement, pacing, speaker framing, audio mix and caption treatment. Ask the Copywriter for any requested original copy or credits.
3. For gameplay, keep the action and any essential HUD or score readable in the crop. For podcasts, identify speakers correctly and preserve the context of the excerpt. Review transcription against the audio before presenting it as captions or quotes.
4. Use approved local editing tools. Ask Media Pipeline Engineer to supply or repair repeatable presets or integrations. Inspect the rendered video for continuity, caption timing, mobile safe areas, legibility, framing, audio and permission-required credits.
5. Return the exact render and optional captions file, thumb brief or approved thumbnail, metadata and rights reference. Include the versions and creative QA result. Route channel brand QA to Brand Lead and the release package to Social for founder approval.

Use the independent channel's own voice, identity and objectives. Treat missing footage, rights, tools or a failed render as a blocker. A storyboard or expected export path is insufficient evidence of an edited video.
