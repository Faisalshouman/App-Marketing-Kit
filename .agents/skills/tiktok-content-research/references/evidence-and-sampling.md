# TikTok evidence and sampling

Platform guidance reviewed in November 2026. Verify the current account interface when a filter or metric affects a decision.

## Use each source for the decision it supports

| Source | Application | Interpretation |
| --- | --- | --- |
| Creator Search Insights | Search for **Creator Search Insights** in TikTok. Where available, inspect **Content gap**, topic details, related searches and videos. Use **Searches by followers** when the account exposes it. Record the displayed label or score and the observation date. | TikTok describes gaps as frequently searched topics with relatively little content. Treat displayed popularity as a platform signal and retain its original unit. A recommendation can differ across accounts, and a number on screen needs a documented definition before it can be reported as query volume. [TikTok Newsroom launch](https://newsroom.tiktok.com/creator-search-insights?lang=en) · [Help Center](https://support.tiktok.com/en/using-tiktok/growing-your-audience/creator-search-insights) |

Record the number inspected, approximate search order and date, and whether results were signed-in or personalized if known. | This is a directional sample. A result can be inaccurate, incomplete, stale, in the wrong language, aimed at another audience, or missing a demonstration. Distinguish these from sparse coverage. TikTok says query match is generally important in Search, and personalizes results using additional signals. ## Record the gap clearly

- Compare the query's intended answer with what each relevant result actually shows. Label each result as answering the question, partly answering it, or serving a different intent. State the omission in terms of the viewer's task, such as “shows the menu, skips the result” or “answers for a different platform.” Record counterexamples and reduce the claim if the strongest result already answers it.
- Distinguish multiple independent demand signals from repeats of the same evidence. A topic label and its related videos can help locate the question and inspect coverage. A dated question recurring across distinct posts adds a different signal. External community threads give leads to sample in TikTok. When access prevents a check, say which evidence is missing. An empty or blocked page is missing data.
- For Search briefs, use the question in plain language where it improves the opening, on-screen label or caption. For For You briefs, make the premise, stakes or first proof legible without prior context. Test these choices against actual performance. TikTok describes both query match and watch/skip behavior, with different weighting across surfaces. [How TikTok recommends content](https://support.tiktok.com/en/using-tiktok/exploring-videos/how-tiktok-recommends-content)
- Check comparable posts at a fixed post age, such as seven days, and record format, duration, market if known, and organic versus paid exposure. When a proposed primary metric is unavailable, name the observed proxy and say which question it can answer. Keep the original values and window rather than treating the ratio as a search rank or causal effect.

Minimum record: channel, audience and locale, query and variants, observed date, demand source, coverage sample and counterexample, proposed gap, opening and proof, asset status, disposition, metric, and checkpoint.
