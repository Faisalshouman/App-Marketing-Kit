# Thumbnail quality

1. Brief the placement, asset type, audience intent and content route using the [decision protocol](references/thumbnail-decision-protocol.md). Record the promise, proof, opening confirmation and payoff against the exact edit or source. When evidence is missing, label concepts as provisional.
2. Follow the protocol's candidate and preview steps. Inspect the actual image or eligible frame at the intended size and crop with the real title and UI overlays. Record the exact candidate and preview version.
3. Grade each candidate using the [grading sheet](references/thumbnail-grading-sheet.md) and a working copy of the [scorecard](references/thumbnail-scorecard.xlsx). Keep one evidence-backed record per candidate in the assigned work item or its private artifact location. Use the grading sheet for interpretation and manually check the same rubric if spreadsheet calculation is unavailable.
4. A known hard-gate failure requires **REVISE**. An unresolved applicable gate requires **REVIEW** with no score unless a known gate failure already decides the outcome. Mark a new cover **READY** only when every applicable gate passes, all eight rows have evidence, the total is at least **85/100**, R1, R3 and R4 each score **2**, and every other row scores at least **1**. Follow the grading sheet for incomplete rows and feed openings. Record any existing below-threshold experimental baseline separately as the protocol specifies.
5. Attach the scored review and preview to the handoff. Regrade after any change affecting the package. READY qualifies the candidate for the workspace review or release workflow. Founder approval governs publication, and audience performance requires a separate measurement.

Use the [video evidence audit](references/thumbnail-video-evidence-audit.md) for the rationale, evidence limits and suggested experiments.
